# Icons

`vip-pass.png` is a copy of the 64x64 placeholder image Bedrock pushes to Roblox
for a resource deployed redacted. It is here so the example points at a real
file, not because it is a good icon.

Replace it with your own 512x512 image before deploying for real.

Bedrock hashes the file contents and records the hash in state, so an unchanged
icon is never re-uploaded.
