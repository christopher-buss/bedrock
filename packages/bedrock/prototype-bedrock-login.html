PROTOTYPE, THROWAWAY

What does bedrock login look like?

Wayfinder ticket "OAuth: sketch what bedrock login looks like" (#695), map "OAuth credentials for ocale and core" (#680). This is a strawman built on option C (per-user app, PKCE, laptop store) with a toggle for option D (shared bedrock app). Every choice here is a proposal to react to, not a decision. The model below uses the Roblox facts settled by the live probe (#682): public client refresh works, a new login revokes the old refresh token, each rotation gives a fresh 90 days, the redirect port must match.

1. The proposal in four terminals

Laptop: log in once

$ bedrock login
Using OAuth app 7301...a9 (from bedrock.config.ts oauth.clientId)
Opening https://apis.roblox.com/oauth/v1/authorize?... in your browser.
Waiting for Roblox on http://localhost:53682/callback ...

  (browser: Roblox consent page, pick experiences, Authorize)

Logged in to Roblox as builderman (user 156)
  Experiences granted: My Obby (5202621917)
  Stored in: macOS Keychain (service "bedrock", account "156@7301...a9")
  Login lasts until 2027-01-18 if unused. Every bedrock command renews it.

Laptop: what am I using?

$ bedrock login status
Credential in use: OAuth login (builderman, 156)
  App:        7301...a9
  Granted:    My Obby (5202621917)
  Expires:    in 87 days (2027-01-18) unless renewed
  Store:      macOS Keychain
  Note: BEDROCK_API_KEY is set and would win over this login.

$ bedrock logout
Revoked the refresh token at Roblox and removed it from macOS Keychain.

Laptop: a deploy that publishes a place

$ bedrock deploy --env production
Error: this deploy publishes 2 places. Roblox only accepts an API key
for place publish, and you are logged in with OAuth.
  Set BEDROCK_API_KEY (or pass --api-key) to deploy places,
  or run `bedrock provision` to apply passes, products and universe
  settings with your login.
  (fails before any request, not with a 401 halfway through)

CI: no login at all

$ CI=true bedrock login
Error: bedrock login is interactive and is not supported in CI.
  In CI, set BEDROCK_API_KEY from a repository secret.

$ CI=true bedrock deploy --env production
  (reads BEDROCK_API_KEY only; never reads a stored login, even if
   a keychain or ~/.config/bedrock/login.json happens to exist)

2. Proposed rules (what the model below enforces)

TopicProposalWhy / what to react to
Commandsbedrock login, bedrock login status, bedrock logoutFlat, like wrangler. Alternative: bedrock auth login|status|logout like gh.
Which appOption C: user registers a private app; oauth.clientId in bedrock.config.ts (a client id is public, not a Credential). Toggle below for D.No review, no shared liability. Cost: each team registers an app with redirect http://localhost:53682/callback.
FlowPKCE S256, no client secret, fixed port 53682, localhost host, state check, 2-minute listener timeout. Port busy: fail with the port named.Port must match exactly (probe). --port only helps if the user also registered that port.
Laptop storeOS keychain first (macOS Keychain, Windows Credential Manager, libsecret). No keychain: ~/.config/bedrock/login.json mode 0600, with a one-line warning. One entry per (user, app).Stores refresh token + its expiry + the current access token. Lives in core, not ocale.
Deploy > 15 mincore builds an ocale credential whose provider refreshes when the access token has under 2 minutes left. Write-ahead: save the rotated refresh token before using the new access token. Identity is oauth:<userId>:<clientId>, so the rate-limit queue does not split.Crash between Roblox's reply and the store write loses the login (try it below). Small window, needs a re-login, no data loss.
Two terminalsA file lock around refresh + store write; the waiter re-reads the store.Single-use refresh tokens make the race real. Toggle the lock off below to see it.
90 days unusedEvery command that refreshes renews 90 days. Expired: fail before any request with "run bedrock login". status warns under 7 days.Only a fully idle laptop hits this.
CIOAuth not supported. API key only. No write-back (option E rejected in this sketch).A copied refresh token rotates once and is gone; and a laptop login revokes it (try it below). Place publish needs a key anyway.
Universe not in grantShown as a 403 with a hint to re-run bedrock login and tick the experience.Exact Roblox response still unprobed (#697).
